# Originality and data provenance

This repository's case-study framing, fictional scenarios, data schemas, generated datasets, scripts, SQL examples, dashboard specifications and documentation were created specifically for this portfolio. They are not copied from an existing public project repository.

It is impossible to guarantee that no similar idea, code pattern or analytical method exists online. SQL joins, EDA, DAX and common Python libraries are standard industry practices. The original work is the specific combination of scenario, data design, implementation and presentation.

Generated CSV files are synthetic and are not actual employer or customer data. The optional scraper collects content from an external practice website; that site's content is not claimed as original.
