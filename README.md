# Suraj Suru | Original Data Analytics Portfolio

Three bespoke case studies with distinct scenarios, custom data structures and analytical questions.

1. [Service Journey Event Log](01_service_journey_event_log/README.md) — workflow transition delays, elapsed time, priority and region comparisons.
2. [Catalogue Intelligence](02_catalogue_intelligence_tableau/README.md) — catalogue price positioning, ratings, responsible web extraction and Tableau.
3. [Channel Mix and Business Performance](03_channel_mix_business_performance_powerbi/README.md) — retail channels, category mix, discount bands, KPIs, SQL and Power BI.

The scenarios, schemas, generated sample data, scripts, SQL examples and dashboard specifications were created for this portfolio. Similar ideas and standard analytical methods may exist elsewhere; global exclusivity cannot be guaranteed. All included generated CSV data is synthetic. The optional scraper retrieves content from an external practice website and is not claimed as original source content.

Run each project's Python script, inspect the outputs, build the Tableau and Power BI workbooks, then add screenshots and your own verified findings before publishing.
